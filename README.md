# JRS_txAdmin

txAdmin recipe for **JRS Core**, a RedM roleplay framework.

## Install

1. txAdmin > **Setup** > **Remote URL Template**
2. Paste:

```
https://raw.githubusercontent.com/JRS-CORE/JRS_txAdmin/main/jrs_recipe.yaml
```

3. Enter your server key, run the recipe and start the server.

The recipe imports the database, installs every resource and writes `server.cfg`.
